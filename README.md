## who i am — A Little About Me

I'm passionate about transforming ideas into **modern, reliable, and user-focused digital products**. I build responsive web experiences, backend services, e-commerce platforms, and cross-platform mobile applications with a focus on maintainable code, practical architecture, and performance.

My development workflow combines hands-on engineering with AI-assisted tools to explore solutions, accelerate implementation, and improve productivity — while keeping problem-solving and code quality at the center.

- 🌐 Building modern web applications with React.js and Next.js

- 📱 Exploring cross-platform mobile development with React Native
- 🛒 Creating e-commerce experiences and administrative dashboards
- 🤖 Using AI-assisted development tools to work smarter
- 📈 Continuously improving my engineering and system-design skills
